# NOVA BLOCKS

8×8 판에 블록을 끌어 놓고 가로·세로 줄을 지우는 네온 블록 퍼즐입니다. 규칙을 설명할 필요가 없는 장르라 모든 연령·국가에서 통하고, 한 판이 짧아 판 사이 광고와 보상형 광고가 자연스럽게 붙습니다. PC(마우스)와 모바일(터치) 모두 지원하고 한국어·영어가 자동으로 바뀝니다.

- 블록 모양 39종, 점수가 오를수록 큰 블록이 자주 나옴 (난이도 상승)
- 공정한 블록 배분: 초반에는 세 블록을 모두 놓을 수 있는 묶음만 주고, 점수가 오르면 이 보장이 줄어 긴장감이 생김
- 콤보(줄을 지운 뒤 3수 안에 또 지우면 배수), 판 전체 클리어 보너스
- 일일 도전: 날짜로 정해진 같은 블록 순서를 모두가 풂 (매일 다시 올 이유)
- 새로고침·앱 전환 후에도 진행 중인 판을 이어서 함
- 이미지·음원 파일 없이 코드로 그리고 합성해서 게임 파일 약 100KB

## 돈을 버는 구조

| 수익원 | 위치 | 설명 |
| --- | --- | --- |
| 보상형 광고 | 막혔을 때 "광고 보고 3줄 지우기"(판마다 1번), 판 중 "광고 보고 블록 바꾸기"(판마다 1번) | 원할 때만 보는 광고라 단가가 높고 불만이 적습니다 |
| 판 사이 광고 | 두 번째 판부터 시작 직전 | 포털이 빈도를 조절합니다 |
| 포털 수익 배분 | CrazyGames, Poki, GameDistribution | 포털 트래픽에 붙는 광고 수익을 나눠 받습니다 |
| 자체 사이트 | `/blocks/` | Google H5 게임 광고(AdSense 계정 필요) |

## 포털에 올리기

```bash
cd blocks
npm test            # 규칙·점수·저장 테스트
node build.mjs      # dist/nova-blocks-crazygames.zip, -poki.zip, -gd.zip
node tools/art.mjs  # 표지·스크린샷·아이콘 다시 만들기 (assets/store/)
```

올리는 곳과 절차는 [NOVA SWARM 안내](../game/README.md#포털에-올리기)와 같고, 파일 이름만 `nova-blocks-…`입니다. 표지는 `assets/store/cover-1920x1080.png`, `cover-800x1200.png`, `cover-800x800.png`, 스크린샷은 `screenshot-1.png`를 씁니다.

## 개발

`npm run sim`은 봇 두 종류로 수백 판을 자동 플레이해 판 길이(수)·점수 분포를 보여 줍니다. 난이도를 바꿀 때 `src/logic.js`의 `friendliness()`·`weightOf()`와 함께 보세요.

정적 서버로 폴더를 열고 주소 끝에 `?portal=fake`를 붙이면 가짜 광고(2초)로 광고 흐름을 확인할 수 있습니다.

| 파일 | 역할 |
| --- | --- |
| `src/pieces.js` | 블록 모양·출현 비중·색 |
| `src/logic.js` | 규칙 (판, 놓기, 줄 지우기, 점수·콤보, 블록 배분, 이어하기). DOM 없음 |
| `sim/run.mjs` | 난이도 시뮬레이터 |
| `src/render.js` | 캔버스 그리기, 판·트레이 배치, 끌기 미리보기, 효과 |
| `src/main.js` | 화면 흐름, 끌기 입력, 광고, 저장 |
| `src/profile.js` | 최고 기록·일일 도전·설정·진행 중인 판 저장 |
| `src/ads.js` | 포털·광고 어댑터 (NOVA SWARM과 같은 코드) |
