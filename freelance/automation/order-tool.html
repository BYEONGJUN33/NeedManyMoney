1주문 파일 넣기

주문 엑셀을 여기로 끌어다 놓으세요스마트스토어·쿠팡·자사몰 주문 내보내기 파일 (.xlsx .xls .csv) · 여러 개 가능

스마트스토어에서 받은 파일에 비밀번호가 걸려 있으면, 엑셀에서 열어 비밀번호를 풀고 다시 저장한 뒤 넣어 주세요.
