# 업무 자동화 샘플 — 설치 없이 브라우저에서 바로 쓰는 도구

크몽 "업무 자동화" 주문을 이런 형태로 납품합니다. **HTML 파일 하나**를 받은 고객이 두 번 눌러 열고, 엑셀을 끌어다 놓으면 결과 엑셀이 내려받아집니다.

- 설치할 것이 없습니다 (윈도우·맥, 크롬·엣지·사파리).
- 고객 파일은 그 컴퓨터 안에서만 처리되고 어디에도 전송되지 않습니다. 개인정보가 담긴 주문 파일도 안심하고 쓸 수 있습니다.
- 납품물이 HTML 하나라 수정·추가 주문도 빠릅니다.

| 파일 | 하는 일 |
| --- | --- |
| [merge-tool.html](merge-tool.html) | 여러 엑셀(지점별·월별)을 한 장으로 합치고 요약표(피벗)를 만듦. 제목 줄 위치·열 순서·열 이름이 달라도 맞춰 합침, 합계 줄 제외, CSV(CP949) 지원 |
| [order-tool.html](order-tool.html) | 쇼핑몰 주문 엑셀 → 택배 일괄등록 파일 + 상품별 피킹 리스트. 같은 받는 분 주문은 한 박스로 합포장, 전화번호 형식 정리, 송장 열 이름을 택배사 양식에 맞게 변경·기억 |
| [samples/](samples/) | 시연용 가짜 데이터 (`python3 samples/make_samples.py`로 다시 만듦) |
| [tests/](tests/) | 브라우저 점검: 샘플을 넣고 결과 엑셀을 다시 열어 원본 합계·수량과 비교 (`node tests/merge-tool.check.cjs`, Playwright 필요) |

두 도구 모두 "예시 데이터로 체험하기" 버튼이 있어 파일 없이도 시연할 수 있습니다.

## 주문 받으면

1. 고객에게 **실제 파일 샘플**(개인정보는 가짜로 바꾼 것)과 **원하는 결과 모양**(손으로 만든 결과 엑셀이면 가장 좋음)을 받습니다.
2. 비슷한 샘플 도구를 복사해 열 이름 사전(SYN, FIELDS), 계산 규칙, 결과 시트 모양을 고칩니다. Claude Code 세션에서 "이 파일을 이 모양으로 바꾸는 도구로 고쳐 줘"라고 하면 됩니다.
3. 고객 샘플로 결과를 만들어 숫자를 대조하는 점검 스크립트(tests 참고)를 함께 돌립니다.
4. HTML 파일과 사용법(그림 3장 정도)을 납품합니다. 인터넷이 막힌 회사라면 SheetJS 라이브러리를 HTML 안에 넣은 "오프라인판"으로 드립니다.

엑셀 매크로(VBA)나 파이썬이 꼭 필요한 일(예: 매일 정해진 시간에 자동 실행, 사내 서버 연동)은 따로 견적을 냅니다.
