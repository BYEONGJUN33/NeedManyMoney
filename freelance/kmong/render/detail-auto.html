지금

  1. 파일을 하나씩 연다
  2. 표 부분만 복사해 붙인다
  3. 열 순서가 달라 다시 맞춘다
  4. 합계 줄을 지우고 피벗을 만든다
  5. 실수가 없는지 다시 확인한다

도구로

  1. 파일을 한꺼번에 끌어다 놓는다
  2. 결과를 화면에서 확인한다
  3. 엑셀로 내려받는다
샘플 1 · 엑셀 합치기 · 요약

지점별 매출 파일 3개 → 합본 + 월별 요약표

지점마다 제목 줄 위치, 열 순서, 열 이름("매출액"과 "매출 금액")이 달라도 하나로 맞춥니다.

합본 줄 수 = 원본 줄 수 (합계 줄 자동 제외)
요약표 총합 = 원본 합계 대조 점검
결과: 요약 시트 + 합본 시트
CSV(엑셀 저장 형식)도 한글 깨짐 없이
샘플 2 · 주문 → 송장 변환

쇼핑몰 주문 엑셀 → 택배 송장 등록 + 피킹 리스트

같은 분이 여러 개 주문하면 한 박스로 합치고, 상품·옵션별 출고 수량을 뽑아 줍니다.

열 이름 보고 자동 연결 (스마트스토어 등)
전화번호 형식 자동 정리
송장 열 이름을 택배사 양식에 맞게
송장 수량 = 피킹 수량 = 원본 대조 점검
