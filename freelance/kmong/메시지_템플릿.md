# 크몽 메시지 템플릿

주문 단계마다 그대로 복사해 쓰고, [ ] 부분만 바꾸세요. 크몽 밖 연락(전화·카톡·외부 링크로 상담 유도, 직접 입금)은 크몽 정책상 금지이니 모든 대화와 결제는 크몽 안에서 합니다.

## 1. 구매 전 문의에 답할 때

```
안녕하세요, 문의 감사합니다!
말씀하신 [업종/작업] 기준으로는 [STANDARD/DELUXE] 패키지가 맞을 것 같아요.
- 포함: [핵심 2~3가지]
- 기간: [n]일, 수정 [n]회
혹시 [확인할 것 1가지, 예: 문의 폼이 필요하신지]만 알려 주시면 정확히 안내드릴게요.
```

## 2. 주문이 들어왔을 때 (자료 요청)

```
주문 감사합니다! 바로 시작할게요.
요청서에서 [빠진 항목]만 추가로 보내 주시면 됩니다.
자료가 모두 오면 [n]일 안에 1차 시안을 보내 드릴게요.
```

## 3. 1차 시안 보낼 때

```
1차 시안 보내 드립니다.
- PC 화면: (이미지 첨부)
- 휴대폰 화면: (이미지 첨부)
수정하고 싶은 부분을 한 번에 모아 보내 주시면 1회로 반영해 드려요. (남은 수정 [n]회)
특히 [문구/사진/색상] 중 바꾸고 싶은 게 있는지 봐 주세요.
```

## 4. 수정 반영 후

```
말씀하신 [n]가지 반영했습니다.
1) [수정 내용]
2) [수정 내용]
확인 부탁드리고, 괜찮으시면 [올리기/납품]을 진행할게요.
```

## 5. 납품할 때

```
작업이 모두 끝나 납품드립니다.
- 사이트 주소: [https://…]
- 소스 파일: 첨부 zip (완성 사이트 + 원본 사진·설정)
- 간단한 문구 고치는 방법: 아래 안내 참고
  · 전화번호·영업시간: 사이트 폴더의 index.html을 메모장으로 열어 해당 글자를 찾아 바꾼 뒤 저장 → 다시 올리기
납품 후에도 제작 실수(오타·링크 오류)는 언제든 무료로 고쳐 드립니다.
만족스러우셨다면 구매 확정 부탁드려요. 감사합니다!
```

## 6. 구매 확정 후 (짧게)

```
구매 확정 감사합니다! 운영하시다 문구·사진 교체가 필요하면 편하게 메시지 주세요.
```

> 리뷰를 대가(할인·추가 작업)와 바꾸는 요청은 하지 마세요. 정중하게 확정만 부탁하는 정도가 안전합니다.
