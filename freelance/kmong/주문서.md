# 의뢰인 요청사항 (크몽 "주문 시 질문"에 넣기)

크몽 서비스 등록 화면의 "의뢰인 요청사항"에 아래 질문을 그대로 넣으면, 주문과 동시에 작업에 필요한 자료가 모입니다.

## 홈페이지·랜딩페이지

```
1. 상호(브랜드명)와 업종을 알려 주세요.
2. 홈페이지로 가장 얻고 싶은 것은 무엇인가요? (예: 예약 문의, 전화 상담, 매장 방문, 앱 사전예약)
3. 연락처·주소·영업시간·카카오톡 채널·인스타그램 주소를 적어 주세요. (넣고 싶은 것만)
4. 꼭 들어가야 할 내용 (메뉴·가격표, 수업 종류, 시공 사례, 자주 묻는 질문 등)
5. 사진을 보내 주세요. 매장·제품·작업 사진, 로고(있다면). 없으면 "없음"이라고 적어 주세요.
6. 원하는 분위기나 참고하고 싶은 사이트 주소가 있다면 알려 주세요. (색상, 느낌)
7. 사업자 정보(상호, 대표자, 사업자등록번호, 주소)를 홈페이지 하단에 넣을까요?
8. 도메인(www.○○.com)이 있나요? 없으면 새로 살지, 무료 주소로 시작할지 알려 주세요.
```

## 엑셀 업무 자동화

```
1. 지금 손으로 하는 작업을 순서대로 적어 주세요. (예: 지점 파일 10개를 열어 복사·붙여넣기 → 월별 합계)
2. 넣을 엑셀 파일 샘플 1~3개를 보내 주세요. 개인정보(이름·전화·주소)는 가짜로 바꾸거나 가려 주세요.
3. 원하는 결과 모양을 보내 주세요. 손으로 만든 결과 엑셀이 있으면 가장 정확합니다.
4. 얼마나 자주 하나요? (매일/매주/매월) 한 번에 파일이 몇 개, 몇 줄 정도인가요?
5. 쓰시는 컴퓨터와 브라우저 (윈도우/맥, 크롬/엣지), 회사에서 인터넷이 막혀 있나요?
```
