# 크몽 등록: 엑셀 업무 자동화

> 납품물은 "더블클릭해서 여는 HTML 도구"입니다. 설치가 없어 회사 PC에서도 바로 쓰고, 파일이 밖으로 나가지 않는 점을 앞세웁니다.

## 카테고리

IT·프로그래밍 → 업무 자동화 (또는 프로그램 개발 → 엑셀·데이터 처리)

## 서비스 제목 (후보)

1. 엑셀 반복 업무, 클릭 한 번 도구로 만들어 드립니다
2. 설치 없는 엑셀 자동화 도구 — 합치기·정리·송장 변환
3. 매일 하는 엑셀 정리, 1분짜리 자동화 도구로 바꿔 드려요

## 검색 키워드

엑셀자동화, 업무자동화, 엑셀합치기, 송장변환, 데이터정리

## 메인 이미지

`images/thumb-auto.png` (652×488) — 고해상도 `images/thumb-auto@2x.png`

## 서비스 설명

```
▶ 이런 일을 자동으로 바꿔 드립니다
- 지점·담당자별로 받은 엑셀 수십 개를 하나로 합치고 월별 합계 내기
- 쇼핑몰 주문 엑셀 → 택배 송장 등록 양식 변환, 같은 분 주문은 한 박스로 합치기
- 거래처마다 다른 양식의 발주서·정산서를 우리 회사 양식으로 정리
- 매주 반복하는 서식 맞추기, 중복 제거, 조건별 분류, 요약표 만들기

▶ 어떻게 쓰나요
받으신 도구(HTML 파일)를 더블클릭 → 엑셀 파일을 끌어다 놓기 → 결과 엑셀 내려받기. 끝입니다.
✔ 설치 없음 — 회사 PC, 맥, 크롬·엣지 어디서나
✔ 보안 — 파일이 인터넷으로 전송되지 않고 내 컴퓨터 안에서만 처리
✔ 양식이 조금 달라도 — 제목 줄 위치·열 순서·열 이름이 달라도 알아서 맞춤
✔ 결과 검증 — 원본 합계와 결과 합계가 맞는지 확인하는 점검을 거쳐 납품

▶ 작업 과정
① 주문 → 지금 쓰는 엑셀 샘플(개인정보는 가려서)과 원하는 결과 모양 보내기
② 도구 제작 + 고객님 샘플로 숫자 대조 점검
③ 시연 화면과 함께 1차 전달 → 수정
④ 납품: 도구 파일 + 그림 사용법

▶ 포트폴리오 (상세 이미지 참고)
- 엑셀 합치기·요약: 지점 3곳 매출 파일 → 합본 + 월별 요약표
- 주문 → 송장 변환: 주문 26줄 → 송장 8박스(합포장) + 피킹 리스트

▶ 확인해 주세요
- 매일 정해진 시간에 저절로 돌아가야 하는 일(예약 실행), 사내 서버·ERP 연동은 별도 견적입니다.
- 엑셀 매크로(VBA)가 꼭 필요하면 먼저 문의해 주세요.
- 고객님 파일 샘플은 작업 후 삭제합니다.
```

## 자주 묻는 질문

```
Q. 회사 보안 때문에 프로그램 설치가 안 되는데요?
A. 설치가 필요 없는 HTML 파일이라 브라우저만 있으면 됩니다. 파일도 밖으로 나가지 않아요.

Q. 엑셀 버전이 오래됐어요.
A. 결과는 .xlsx로 나오고, 엑셀 2010 이상이면 열립니다. 넣는 파일은 .xlsx·.xls·.csv 모두 됩니다.

Q. 나중에 양식이 바뀌면요?
A. 열 이름이 조금 바뀌는 정도는 도구가 알아서 맞춥니다. 크게 바뀌면 양식 추가 옵션으로 고쳐 드려요.
```
