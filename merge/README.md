# NOVA MERGE

통 안에 빛나는 구슬을 떨어뜨리고, 같은 구슬 두 개가 닿으면 한 단계 큰 구슬로 합쳐지는 물리 퍼즐입니다("수박 게임" 계열). 조작이 한 손가락이라 모든 연령이 바로 하고, 큰 구슬이 터지는 순간이 영상·공유로 퍼지기 좋습니다. PC(마우스·키보드)와 모바일(터치) 모두 지원하고 한국어·영어가 자동으로 바뀝니다.

- 구슬 11단계 (가장 큰 NOVA 두 개가 합쳐지면 사라지며 큰 보너스), 표정과 눈 깜빡임
- 직접 만든 물리 엔진 (충격량 접촉 + 겹침 보정, 하위 단계 4회): 쌓여도 떨리지 않고 통 밖으로 나가지 않음
- 일일 도전 (날짜로 정해진 같은 구슬 순서), 새로고침해도 이어서 하기, 진화표로 다음 목표 표시
- 이미지·음원 파일 없이 코드로 그리고 합성

## 돈을 버는 구조

| 수익원 | 위치 | 설명 |
| --- | --- | --- |
| 보상형 광고 | 넘쳤을 때 "위쪽 절반 비우기"(판마다 1번), 판 중 "작은 구슬 터뜨리기"(판마다 1번) | 원할 때만 보는 광고 |
| 판 사이 광고 | 두 번째 판부터 시작 직전 | 포털이 빈도를 조절합니다 |
| 포털 수익 배분 | CrazyGames, Poki, GameDistribution | 포털 트래픽 광고 수익 배분 |
| 자체 사이트 | `/merge/` | Google H5 게임 광고(AdSense 계정 필요) |

## 포털에 올리기

```bash
cd merge
npm test            # 규칙·물리·저장 테스트
npm run sim         # 봇 자동 플레이: 판 길이·점수·최고 단계, 물리 안정성
node build.mjs      # dist/nova-merge-crazygames.zip, -poki.zip, -gd.zip
node tools/art.mjs  # 표지·스크린샷·아이콘 다시 만들기 (assets/store/)
```

올리는 곳과 절차는 [NOVA SWARM 안내](../game/README.md#포털에-올리기)와 같고 파일 이름만 `nova-merge-…`입니다.

## 개발

정적 서버로 폴더를 열고 주소 끝에 `?portal=fake`를 붙이면 가짜 광고(2초)로 광고 흐름을 확인할 수 있습니다.

| 파일 | 역할 |
| --- | --- |
| `src/logic.js` | 규칙과 물리 (구슬 크기·점수·출현 비중·위험선, 합치기, 이어하기). DOM 없음 |
| `src/render.js` | 캔버스 그리기 (구슬 스프라이트·얼굴, 통, 조준선, 다음 구슬, 진화표, 효과) |
| `src/main.js` | 화면 흐름, 조준·떨어뜨리기 입력, 광고, 저장 |
| `src/profile.js` | 최고 기록·최고 단계·일일 도전·설정·진행 중인 판 저장 |
| `sim/run.mjs` | 난이도·물리 시뮬레이터 |
